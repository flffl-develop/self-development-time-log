# Self-Development Time Log

A personal web app for recording and tracking daily self-development time.

## Features
- Record daily study and self development time
- View time logs on a monthly calendar
- Set monthly target time
- Choose a monthly theme
- Save data using LocalStorage
- Use the app without creating an account

## Tech Stack
-HTML
-CSS
-JavaScript
-LocalStorage
-GitHub Pages
